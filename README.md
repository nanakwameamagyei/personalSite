# Personal Portfolio Website

A modern, responsive portfolio website built with HTML and Tailwind CSS, showcasing my work, case studies, and professional background.

## 🚀 Live Demo
[View Live Site](https://nana-kwame-amagyei.vercel.app/)

## 📁 Project Structure

```
personalSite/
├── index.html              # Homepage
├── case-studies.html       # Case studies showcase
├── blog/                   # Blog section (in development)
├── contact/                # Contact page (in development)
├── assets/
│   ├── docs/               # Documents
│   ├── css/
│   │   └── tailwind.css    # Tailwind CSS
│   ├── js/
│   │   └── script.js       # Custom JavaScript
│   └── images/             # Images and icons
├── README.md               # This file
└── .gitignore              # Git ignore file
```

## ✨ Features

- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Modern UI**: Clean, professional design with proper typography and spacing
- **Case Studies**: Detailed project breakdowns with problem-solution approach
- **Accessibility**: Semantic HTML and proper ARIA labels
- **Performance**: Optimized with minimal dependencies
- **Back-to-Top Button**: Smooth scroll functionality for long pages

## 🛠️ Technologies Used

- **HTML5**: Semantic markup

- **JavaScript**: Vanilla JS for interactivity
- **Git**: Version control

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Git (for development)
- VS Code
  
### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/nanakwameamagyei/personalSite.git
   cd personalSite
   ```

2. Open in your browser:
   - Simply open `index.html` in your browser
   - Or use a local server like Live Server extension

### Building
This is a static site - no build process required. All Tailwind CSS is pre-compiled.

## 🎨 Customization

### Updating Content
- Edit HTML files directly
- Update text, links, and images as needed
- Modify `tailwind.css` for styling changes

### Adding New Pages
1. Create new HTML file in root directory
2. Copy the basic structure from existing pages
3. Add navigation links in relevant pages
4. Deploy to see changes

## 🌐 Deployment

### Vercel Deployment (Recommended)
1. Push changes to GitHub:
   ```bash
   git add .
   git commit -m "Your message"
   git push origin main
   ```

2. Connect repository to Vercel
3. Automatic deployments on push to `main`

### Manual Deployment
- Any static hosting service (Netlify, GitHub Pages, etc.)
- Simply upload the files to your hosting provider

## 📱 Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

## 🧪 Testing
- Test in multiple browsers (Chrome, Firefox, Safari, Edge)
- Check responsiveness on different devices
- Validate HTML at [validator.w3.org](https://validator.w3.org)
- Test accessibility with Lighthouse
